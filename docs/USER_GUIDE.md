# 本地工作台操作说明

## 登录与账号

双击根目录 `start.cmd`，在浏览器访问 <http://127.0.0.1:8501>。首次进入需登录；未注册账号可在登录页直接注册并登录（无需选择角色），注册即开通、可立即使用。

- 不区分录入 / 复核身份：登录后即可进行导入、复核等全部业务操作，数据按账号独立存储（每个账号是独立的工作台）。
- 管理员（admin / admin123，正式部署后请尽快修改密码）额外可进入「用户与权限」管理账号（查看、移除、改密码）。
- 普通成员可在侧边栏「账号设置」自助**注销账户**（需输入密码确认，注销后账号及其任务数据永久删除，不可恢复）；管理员账号不可自助注销。
- 「操作/复核人」不再手填，自动取当前登录用户名。

## 启动和演示

首次环境安装及模型下载需要联网；模型就绪后使用不需要网络。保持启动窗口运行，关闭窗口可停止前台工作台。登录后进入主界面，在对账总览点击“加载合成演示并运行对账”。已有任务时须先确认替换，当前任务及复核将被替换。演示数据独立构造，不来自财务处。

## 导入授权数据

进入导入与字段确认，为三类来源分别选择文件。选择一个或多个工作表，设置表头行，检查预览和字段映射。金额必填，同一列不能映射到多个标准字段；币种、方向等缺失默认规则须检查。

需要时点击本地 AI 建议，待完成后更新页面，点击填入建议，检查后确认映射。AI 建议未确认不会生效。对每个工作表点击“确认映射并加入待对账数据”。同文件同工作表再次确认会替换该暂存项；重复文件不重复添加。

检查暂存清单，可以移除错误工作表。三类数据齐全后填写任务名，勾选确认，点击开始规则对账。新任务替换当前任务，只有一个当前任务；需要保留结果请先导出。

## 复核和候选

进入结果与人工复核，按自动分类、人工状态筛选并选择结果组。查看标准化记录、两组关系、原始内容及行号。选择确认或驳回，保存结论；驳回必须填写原因。

银行孤立记录可以查看最多五个尚未分配候选，点击本地 AI 解释候选。建议完成后人工选择，填写关联依据并确认。金额重新计算，仍有冲突时保留未匹配，差额不会因人工操作消失。关联后的新结果必须重新复核。

任务每次操作自动保存到本机 SQLite。重启工作台会恢复当前任务及复核记录。无法解析的原始行保留在质量清单，不自动跳过。

## AI 状态与导出

本地 AI 与记录页面提供就绪检查、建议详情与人工采纳记录。请求运行中可以取消；超时和取消不会自动重试或调用云模型。若模型未就绪，运行 `scripts/setup-ai.ps1` 下载，再运行 `scripts/start-ai.ps1`。

导出完整 Excel，包含汇总、三类结果、关系、标准化与原始数据、质量问题、复核、AI 和映射记录。金额文本保留分值精度，公式样式文本不执行。

导出、SQLite、日志及截图都可能含受限派生数据。仅公开演示独立合成数据，项目结束按数据清单清理。
