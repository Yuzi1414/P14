# 本地工作台操作说明

## 登录与账号

双击根目录 `start.cmd`，在浏览器访问 <http://127.0.0.1:8501>。首次进入需登录；未注册账号可在登录页直接注册并登录，注册时必须选择角色（导入 / 复核），注册即开通、可立即使用。

账号分为两类角色，权限按角色隔离：

| 角色 | 可进入页面 | 权限边界 |
| --- | --- | --- |
| 导入 | 对账总览、导入与字段确认、交付与说明 | 只能导入表格、确认字段映射、建立（替换）对账任务；看不到复核页，不能提交复核结论 |
| 复核 | 对账总览、结果与人工复核、AI 辅助与记录、交付与说明 | 只能查看对账结果并提交确认 / 驳回结论；不能导入、替换任务、补配候选或建立关联，也不能发布 / 载入对账包 |
| 管理员 | 全部页面 + 用户与权限 | 拥有导入与复核两种权限，并可为账号指定角色 |

- 管理员（admin / admin123，正式部署后请尽快修改密码）：在「用户与权限」为账号选择「导入 / 复核」并保存，账号需**重新登录**后生效。改造前注册的旧账号角色显示「未分配」，未指定角色时登录会被拦截，无法进入工作台。
- 「用户与权限」页底部的「操作记录」按时间倒序列出每个账号做过的每一步（登录、确认字段映射、建立对账、提交复核结论、人工建立关联、共享、修改密码、管理员改角色 / 移除账号等），可按用户筛选并导出 CSV；账号被移除后记录仍保留。失败的操作不写入。
- 普通成员可在侧边栏「账号设置」自助**注销账户**（需输入密码确认，注销后账号永久删除，不可恢复）；管理员账号不可自助注销。对账数据属于共享工作区，注销个人账号不会清空。
- 「操作/复核人」不自动手填，取当前登录用户名。
- 导入与复核共用同一个对账工作区：导入账号建立的任务，复核账号登录后直接看到同一份结果与复核记录，无需手动同步。

## 启动和演示

首次环境安装及模型下载需要联网；模型就绪后使用不需要网络。保持启动窗口运行，关闭窗口可停止前台工作台。登录后进入主界面，在对账总览点击“加载合成演示并运行对账”（仅导入 / 管理员可见）。已有任务时须先确认替换，当前任务及复核将被替换。演示数据独立构造，不来自财务处。

## 导入授权数据

进入导入与字段确认，为三类来源分别选择文件。选择一个或多个工作表，设置表头行，检查预览和字段映射。金额必填，同一列不能映射到多个标准字段；币种、方向等缺失默认规则须检查。

需要时点击本地 AI 建议，待完成后更新页面，点击填入建议，检查后确认映射。AI 建议未确认不会生效。对每个工作表点击“确认映射并加入待对账数据”。同文件同工作表再次确认会替换该暂存项；重复文件不重复添加。

检查暂存清单，可以移除错误工作表。三类数据齐全后填写任务名，勾选确认，点击开始规则对账。新任务替换当前任务，只有一个当前任务；需要保留结果请先导出。

## 复核和候选

进入结果与人工复核（复核 / 管理员可进入），按自动分类、人工状态筛选并选择结果组。查看标准化记录、两组关系、原始内容及行号。选择确认或驳回，保存结论；驳回必须填写原因。

复核账号为只读：候选补配、建立关联属于修改对账数据，页面只对该角色显示只读提示，相关按钮不出现。

银行孤立记录可以查看最多五个尚未分配候选（仅导入 / 管理员可操作），点击本地 AI 解释候选。建议完成后人工选择，填写关联依据并确认。金额重新计算，仍有冲突时保留未匹配，差额不会因人工操作消失。关联后的新结果必须重新复核。

任务每次操作自动保存到共享工作区（`runtime/tasks/workspace.db`）。重启工作台会恢复当前任务及复核记录。改造前按账号 / 设备分库的任务，会在对应账号首次登录且工作区为空时自动复制进来。无法解析的原始行保留在质量清单，不自动跳过。

## AI 状态与导出

本地 AI 与记录页面提供就绪检查、建议详情与人工采纳记录。请求运行中可以取消；超时和取消不会自动重试或调用云模型。若模型未就绪，运行 `scripts/setup-ai.ps1` 下载，再运行 `scripts/start-ai.ps1`。

导出完整 Excel，包含汇总、三类结果、关系、标准化与原始数据、质量问题、复核、AI 和映射记录。金额文本保留分值精度，公式样式文本不执行。

导出、SQLite、日志及截图都可能含受限派生数据。仅公开演示独立合成数据，项目结束按数据清单清理。
