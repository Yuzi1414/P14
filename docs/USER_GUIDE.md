# 本地工作台操作说明

## 登录与账号

双击根目录 `start.cmd`，在浏览器访问 <http://127.0.0.1:8501>。首次进入需登录；未注册账号可在登录页直接注册并登录，注册时必须选择角色（导入 / 复核 / 录入+复核），注册即开通、可立即使用。

账号分为三类角色，权限按角色隔离：

| 角色 | 可进入页面 | 权限边界 |
| --- | --- | --- |
| 导入 | 对账总览、导入与字段确认、交付与说明 | 只能导入表格、确认字段映射、建立（替换）对账任务；看不到复核页，不能提交复核结论 |
| 复核 | 对账总览、结果与人工复核、AI 辅助与记录、交付与说明 | 只能查看对账结果并提交确认 / 驳回结论；不能导入、替换任务、补配候选或建立关联，也不能发布 / 载入对账包 |
| 录入+复核 | 对账总览、导入与字段确认、结果与人工复核、录入记录、AI 辅助与记录、交付与说明 | 同时具备导入与复核权限，并可在「录入记录」查看其他账号的录入批次、确认人和明细；没有用户与权限管理，不能改角色、不能移除账号 |
| 管理员 | 全部页面 + 用户与权限 | 拥有导入与复核两种权限，并可为账号指定角色 |

- 管理员（admin / admin123，正式部署后请尽快修改密码）：在「用户与权限」为账号选择「导入 / 复核 / 录入+复核」并保存，账号需**重新登录**后生效。改造前注册的旧账号角色显示「未分配」，未指定角色时登录会被拦截，无法进入工作台。
- 「用户与权限」页底部的「操作记录」按时间倒序列出每个账号做过的每一步（登录、确认字段映射、建立对账、提交复核结论、人工建立关联、共享、修改密码、管理员改角色 / 移除账号等），可按用户筛选并导出 CSV；账号被移除后记录仍保留。失败的操作不写入。
- 普通成员可在侧边栏「账号设置」自助**注销账户**（需输入密码确认，注销后账号永久删除，不可恢复）；管理员账号不可自助注销。任务数据按账号 + 设备隔离，注销时会清理该账号的数据。
- 任务默认按**账号 + 设备**隔离：本设备导入的数据只有本设备可见，其他设备、其他账号都看不到；需要让其他账号/设备查看时，由导入账号点「发布到云端共享」，对方再点「从云端共享载入」即可看到同一份任务。
- 「录入+复核」在「录入记录」页可看到本设备当前任务的导入批次、确认人和明细，并可按录入人筛选、导出 CSV；载入云端共享任务后也能看到发布者的录入记录。
- 「操作/复核人」不自动手填，取当前登录用户名。

## 启动和演示

首次环境安装及模型下载需要联网；模型就绪后使用不需要网络。保持启动窗口运行，关闭窗口可停止前台工作台。登录后进入主界面，在对账总览点击“加载合成演示并运行对账”（仅导入 / 录入+复核 / 管理员可见）。已有任务时须先确认替换，当前任务及复核将被替换。演示数据独立构造，不来自财务处。

## 导入授权数据

进入导入与字段确认，分别为银行流水与财务往来账选择文件。选择一个或多个工作表，设置表头行，检查预览和字段映射。付款单位与金额必填，业务日期可选（只作备注，不参与判定）；同一列不能映射到多个标准字段。

需要时点击本地 AI 建议，待完成后更新页面，点击填入建议，检查后确认映射。AI 建议未确认不会生效。对每个工作表点击“确认映射并加入待对账数据”。同文件同工作表再次确认会替换该暂存项；重复文件不重复添加。

检查暂存清单，可以移除错误工作表。两类数据齐全后填写任务名，勾选确认，点击开始规则对账。对账只比较付款单位与金额：付款单位与金额都相同的记录配为一组；金额相同但付款单位不同列为异常差异；缺一侧记录、付款单位为空或金额无效保留为未匹配。新任务替换当前任务，只有一个当前任务；需要保留结果请先导出。

## 复核和候选

进入结果与人工复核（复核 / 录入+复核 / 管理员可进入），按自动分类、人工状态筛选并选择结果组。查看标准化记录、配对依据、原始内容及行号。选择确认或驳回，保存结论；驳回必须填写原因。

已匹配的组通常数量最多、判断也最直接，页面顶部提供「一键确认全部已匹配（N 组）」：点一次就把当前所有**自动分类 = 已匹配、且仍是待复核**的组记为确认，操作人取当前登录账号，每组单独留痕（导出可见），备注统一写「一键确认全部已匹配组（未逐组填写备注）」。按钮上的数字是本次会确认的组数，处理完变成 0 组并置灰。异常差异、未匹配以及已驳回的组都不受影响，仍需逐组查看依据后单独提交。

复核账号为只读：候选补配、建立关联属于修改对账数据，页面只对该角色显示只读提示，相关按钮不出现。「录入+复核」不显示该只读提示，可以补配候选和建立关联。

单边孤立记录（银行或往来）可以查看最多五个尚未分配候选（仅导入 / 录入+复核 / 管理员可操作），点击本地 AI 解释候选。建议完成后人工选择，填写关联依据并确认。关联后按付款单位与金额重新计算，仍有冲突时保留异常差异或未匹配，差额不会因人工操作消失。关联后的新结果必须重新复核。

任务每次操作自动保存到本设备的分库（本地 `runtime/tasks/{账号}_{设备}.db`，线上为 Supabase 对应 task_key）。重启工作台会恢复当前任务及复核记录；换设备时用「发布到云端共享 / 从云端共享载入」同步，或导出对账包手动迁移。无法解析的原始行保留在质量清单，不自动跳过。

## AI 状态与导出

本地 AI 与记录页面提供就绪检查、建议详情与人工采纳记录。请求运行中可以取消；超时和取消不会自动重试或调用云模型。AI 不可用时侧栏显示「规则引擎模式」，核对结果不受影响；需要 AI 建议时运行 `scripts/setup-ai.ps1` 下载，再运行 `scripts/start-ai.ps1`。

导出完整 Excel，包含汇总、三类结果（已匹配 / 未匹配 / 异常差异）、配对关系、标准化与原始数据、质量问题、复核、AI 和映射记录。金额文本保留分值精度，公式样式文本不执行。

导出、SQLite、日志及截图都可能含受限派生数据。仅公开演示独立合成数据，项目结束按数据清单清理。
