# 实现审查与测试记录

验证日期：2026-10-16。环境：Windows、Python 3.12、Ryzen 7 8845H、约 28 GB 内存。测试全部使用独立合成数据，未使用财务处样例。

## 已验证结果

- 自动化回归：`python -m pytest -q`，39 项通过。语法编译及 `pip check` 通过。
- 固定样例：45 条原始记录，19 个结果组；已匹配 4、未匹配 13、异常差异 2，初始全部待复核。标准答案独立编写，不从引擎输出反向生成。
- 两组关系与三方汇总覆盖检查通过：无原始记录遗漏，同一关系内无重复消费。
- 真实浏览器完成三类 Excel 上传、字段确认、规则对账、复核保存、页面恢复及下载。下载文件通过 openpyxl 重读，标准化数据 45 行，包含 AI 成功和取消记录。
- 演示中人工补充无编号银行记录的收费、往来两组关联后，结果由 19 组变为 17 组，已匹配由 4 组变为 5 组；关联依据与 AI 采纳情况保留。当前任务为该人工处理后的演示状态，重新加载合成演示可恢复初始基线。
- 本地 Ollama `qwen3:4b` 实际完成字段映射和候选解释，所选候选符合合成样例预期。最新独立验证的两次调用约 26.8 秒、26.8 秒；8 字段 UI 请求约 70.7 秒。不同输入与模型加载状态耗时不同，不构成性能承诺。
- Python 验证客户端禁止非回环连接后，完成实际模型调用、合成导入、人工建立两组关联、复核、SQLite 保存恢复及 Excel 导出。浏览器禁止非本机请求后重载，恢复出 4/13/2/19 的指标。

详细机器记录见 `ai-verification.json`、`ui-verification.json`、`benchmark.json`，演示截图见 `output/playwright/`。客户端网络限制不是整机物理断网测试，没有修改系统网络、证书或信任配置。

## 场景覆盖

| 类别 | 场景与断言 |
|---|---|
| 规则 | 完整三方、缺来源、明确金额差异、重复编号、同额不同对象、批次一对多/多对一、退款、方向冲突、跨日、缺日期、冲突批次 |
| 标准化 | Decimal 分值、千分位、负数、超过分的精度拒绝、日期格式、文本与数字补零编号、多表与非首行表头、坏行保留、重复表头 |
| 公式与导出 | 未缓存金额公式拒绝但原公式文字保留、所有文本以字符串写入、长文本分段无截断、导出数量与任务一致 |
| 复核 | 自动分类独立于人工确认、驳回原因必填、持久化恢复、关联重算、旧结果确认不能沿用到新结果、禁止重复分配候选 |
| AI | 结构化输出、未知字段/重复映射拒绝、越界候选拒绝、无效JSON、HTTP错误、超时、服务关闭、串行限制、取消、程序比较事实独立于模型文字 |
| 界面 | 合成任务加载、真实文件导入、复核表单、页面切换、重启恢复、AI建议和取消、工作簿下载 |

## 规模实测

三类来源各 10000 条，总计 30000 条。产生 20000 个关系结果和 10000 个三方组，全部符合合成场景预期。最近记录规则引擎及覆盖检查用时 **0.8175 秒**，RSS 采样从约 **42.81 MB** 到 **61.21 MB**。

该测量不含 Excel 读写、模型推理或浏览器渲染，RSS 不是内存峰值；本机负载会影响耗时。原申报没有规定性能 SLA。

## 审查修正

1. 金额精确到分，编号保持文本与明确补零格式；无效行不被静默删除。
2. 重复文件/工作表不反复加入，同一工作表不能冒充不同来源。
3. 自动分类与人工结论独立；人工建立关联后重算差额、重新复核。
4. 源数据与金额不由模型改写，模型候选集合受校验，失败不切云服务。
5. 模型曾把名称相似描述为完全一致。除要求中文外，增加 `verified_facts`，由程序逐字段比较并显示缺失值，避免把模型解释当作已验证事实。
6. 导出文本不执行公式，超过单元格长度限制时引用分段内容，防止截断。
7. 应用与模型仅监听回环地址，关闭 Streamlit 使用统计及 Ollama 云功能。安装器只下载公开软件并核对官方摘要。

## 当前边界

尚未获得财务处 Excel 样例、正式规则确认及业务人员验收，因此本记录仅证明演示原型与合成测试完成。日期、退款、手续费、多对多和真实方向口径须按待确认表处理。

没有多用户权限、正式审计身份或生产级并发控制；模型语义解释仍可能错误，程序事实检查也不证明业务关系真实。所有输出仍须人工复核，不用于正式财务结算。
