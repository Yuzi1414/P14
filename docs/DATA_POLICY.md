# 数据使用与清理说明

原申报要求财务处提供的脱敏模拟样例仅限本项目学生与指导老师访问，不上传公网、不外传、不复制留存，项目结束全部删除。独立合成数据与这些受限样例分开管理。

## 运行管理

原始文件只读导入，应用不覆盖源文件。数据处理和模型推理在本机完成，应用不使用公网模型、CDN、远程字体或统计上报。Ollama 关闭云功能，仅监听回环地址。模型与依赖下载只涉及公开软件。

`runtime/current.db` 保存原始字段、标准化数据、映射和操作记录；`runtime/` 日志与 `.runtime/` 运行时被版本库忽略。导出工作簿、截图、测试记录可能包含派生内容，同样受数据授权约束。本机没有多用户鉴权，设备和文件权限必须由项目成员控制。

建议把授权样例放在 `restricted_data/`，不得放在 `samples/`、代码或公开文档。运行时和受限目录已加入 `.gitignore`。Git 忽略不等于加密或删除。

## 项目结束清理清单

1. 列出财务处提供的原始样例位置、当前任务数据库、导出位置、截图、备份和含业务内容的 AI/人工记录。
2. 关闭本项目工作台与模型服务，核对每个绝对路径属于本项目或明确登记位置。
3. 按清单删除受限原始与派生数据，不递归删除用户目录、不删除无关文件。清理记录只保留路径类别、日期、执行人与完成情况，不保留数据内容。
4. 检查回收站、同步盘和自行创建的备份是否仍有受限副本；按学校规定处理。普通删除不是可靠介质擦除。
5. 独立合成样例、源码、空白模板、模型及不含业务内容的测试方法可按授权保留。

应用不自动执行项目结束清理，避免误删用户文件。实际收到财务样例后须维护数据清单并由负责人核查。
